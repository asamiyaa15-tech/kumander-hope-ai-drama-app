# KUMANDER HOPE AI DRAMA APP

A static, mobile-friendly AI drama prompt library.

## Deploy on Netlify
This is a plain HTML/CSS/JavaScript site. In Netlify manual deploy, publish the folder containing `index.html`, or connect this repository and set:
- Build command: leave blank
- Publish directory: `.`

No API keys or environment variables are required.

Premium pricing is a prototype display only. No payments are collected or memberships activated.
